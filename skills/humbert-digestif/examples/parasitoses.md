## Instructions

Ce document décrit les parasitoses intestinales selon l'approche du Pr Humbert.

---

## HELMINTHES (Vers Ronds - Nématodes)

### Types
- **Ascaris** : vers longs (20-30 cm)
- **Oxyures** : petits vers blancs (1 cm)
- **Trichocéphales**
- **Ankylostomes**
- **Anguillules** (strongyloïdes)

### Contamination
- Œufs dans terre, aliments souillés
- Mains sales
- Eau contaminée

### Localisation
- **Collés sur muqueuse intestinale** (pas dans selles !)
- Muqueuse enflammée (MICI) → adhérence facilitée
- Se momifient parfois

### Symptômes

**Digestifs** :
- Douleurs abdominales
- Diarrhée ou constipation
- Ballonnements
- Glaires

**Cutanés** :
- **Prurit anal** (oxyures surtout)
- **Prurit cuir chevelu** (DÉCOUVERTE HUMBERT)
- **Urticaire chronique**
- **Eczéma**

**Gynécologiques** (DÉCOUVERTE HUMBERT) :
- **Pseudocystites** : brûlures urinaires SANS infection
  - Pas leucocytes (< 100 000)
  - Mais bactéries (E. coli millions)
- **Pseudomycoses** : prurit vulvaire SANS candida
  - Pas placard émietté caractéristique
  - Mais démangeaisons, pertes
- **"Cystites + mycoses = parasites intestinaux"**

**Généraux** :
- Fatigue
- Perte poids
- Anémie

### Rôle Immunodépresseur (DÉCOUVERTE MAJEURE)

**Helminthes → baisse immunité contre** :
- **Herpès** : récidives fréquentes
- **Papillomavirus** :
  - Verrues enfants
  - Condylomes adultes
  - **Cancer col utérus** (HPV)
- **"Albendazole = 1er traitement cancer col utérus"** (publications)

### Diagnostic

**Biologie** :
- **Éosinophilie** : >500/mm³
  - **Courbe de Lavier** : monte puis descend (cycle)
  - Peut être normale entre cycles
  - **Regarder prises sang anciennes !**
- **Sérologie ascaris** : >2 unités = positif (pas >15 !)
- **IgE totales** : élevées

**Parasitologie selles** : **INUTILE**
- Vers collés muqueuse, pas dans selles
- Positif seulement si infestation massive

### Traitement

**Albendazole** (Zentel) :
- **3 jours**
- Puis **retraitement 8-10 jours après** (larves)
- Si MICI ou déficit IgA : **tous les 6 mois**

**Flubendazole** (Fluvermal) : alternative

**Ivermectine** : si toxocarose systémique

## TOXOCAROSE (Toxocara canis/cati)

### Contamination
- Œufs chien/chat dans terre
- Ingestion (mains sales, légumes)
- Embryonnation œufs par froid

### Cycle
- Larves intestin
- **Si hyperperméabilité → passage sang**
- Migration organes (foie, poumons, cerveau, œil)

### Symptômes

**Cutanés** :
- **Urticaire chronique**
- **Eczéma** (bras, visage)
- **Œdèmes**

**Viscéraux** :
- Toux (passage poumons)
- Douleurs abdominales
- Hépatomégalie

**Oculaires** :
- Granulome rétine
- Baisse vision brutale
- **Énucléation si confondu avec rétinoblastome** (années 50)

**Neurologiques** :
- Épilepsie (larve cerveau)
- Troubles cognitifs

### Diagnostic
- **Sérologie toxocara** : >2 unités = positif
- Éosinophilie
- **Lien avec MICI** : 90% toxocaroses ont MICI

### Traitement
- **Ivermectine** : 200 µg/kg dose unique
- Albendazole : alternative

## PROTOZOAIRES

### Giardiase (Lambliase)

**Contamination** : eau contaminée

**Symptômes** :
- Diarrhée aqueuse
- Ballonnements
- Malabsorption
- Urticaire

**Diagnostic** :
- Parasitologie selles (ici utile)
- Biopsies duodénales

**Traitement** : métronidazole

### Amibiase

**Contamination** : eau, aliments contaminés

**Symptômes** :
- Diarrhée sanglante
- Douleurs abdominales
- **Peut mimer Crohn !**

**Cas Clinique** : Le juriste luxembourgeois
- Diagnostic Crohn établi, biothérapie échec
- Vécu Centrafrique → recherche amibe
- Sérologie positive → traitement → guérison complète

**Diagnostic** :
- Parasitologie selles
- Sérologie

**Traitement** : métronidazole + tiliquinol
