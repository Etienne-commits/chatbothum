## Instructions

Ce document décrit les intolérances alimentaires selon l'approche du Pr Humbert.

---

## GLUTEN

### Modification Structurelle du Blé (CONCEPT CLÉ)

**"Le blé moderne n'est plus le blé de nos grands-parents"**

- Avant 2010 : blé à 12 chromosomes
- Aujourd'hui : blé à **40 chromosomes** (hybridations)
- + Pesticides (glyphosate)
- + Enrichissement en gluten (levée rapide industrielle)

**"Je dis à mes patients : le petit mitron qui faisait lever la pâte pendant 24 heures, il n'existe plus. Aujourd'hui plus de gluten = lève plus vite"**

- Conséquence : gluten plus irritant pour intestin
- Explosion intolérances ces 20 dernières années

### Maladie Cœliaque (1/150)

**Définition** :
- Maladie auto-immune génétique
- HLA DQ2 ou DQ8
- Atrophie villosités intestinales
- Malabsorption sévère

**Symptômes** :
- Diarrhée chronique (ou constipation)
- Ballonnements, douleurs
- Fatigue intense
- Carences multiples
- Retard croissance enfant

**Diagnostic** :
- **Anticorps anti-transglutaminase IgA** : >10 = positif
- Anticorps anti-gliadine IgG (plus spécifiques)
- **Endoscopie + biopsies** : atrophie villosités
- **AVANT régime sans gluten !**

**Traitement** :
- Régime sans gluten **À VIE strict**
- Supplémentation carences

### Intolérance Non-Cœliaque (NCGI) (1/10)

**"La plus fréquente, la plus méconnue"**

**Symptômes** :
- Digestifs : ballonnements, diarrhée, douleurs
- **Extra-digestifs** : fatigue, céphalées, brouillard mental
- Cutanés : eczéma, acné
- Articulaires : douleurs
- Neurologiques : vertiges

**Diagnostic** :
- **Anticorps anti-transglutaminase** : <10 (négatifs)
- **Pas atrophie villosités**
- **Signes cutanés pathognomoniques** (DÉCOUVERTE HUMBERT) :
  1. **Coudes** : hyperkératose pavimenteuse (peau épaisse)
  2. **Genoux** : zone rectangulaire striée sous rotule
  3. **Bras** : kératose pilaire (picots, chair poule)
- **"Si ces 3 signes → intolérance gluten quasi certaine"**

**Traitement** :
- Régime sans gluten **1 an strict** (pas 3 semaines)
- Réintroduction progressive possible après

**Lien Hyperlaxité** :
- Rhume foins → 80% intolérance gluten
- Otites enfance → intolérance lait → puis gluten

## LAIT DE VACHE

### Intolérance Protéines (≠ lactose)

**Protéines en cause** :
- Caséine
- Lactoglobuline
- Lactalbumine

**Signes Nourrisson** (MARQUEURS ESSENTIELS) :
- **Régurgitations** (pas reflux mécanique)
- **Coliques** (pleurs, tortillements)
- **Constipation ou diarrhée**
- **Otites, bronchites, bronchiolites à répétition**
- **Eczéma atopique**
- **Courbe croissance infléchie**

**"Otites + constipation = intolérance lait vache 100%"**

### Le Reflux : Souvent Allergique, Pas Mécanique

**"On vous dit reflux gastro-œsophagien, on vous donne des IPP... Mais c'est souvent une réaction allergique de l'estomac !"**

- Protéines lait vache → inflammation estomac → "reflux"
- Les IPP masquent mais ne guérissent pas
- **Test diagnostic** : arrêt lait vache 2-3 semaines
  - Si amélioration = intolérance protéines lait
  - Pas besoin fibroscopie dans ce cas
- Chez adulte aussi : reflux chronique = penser lait

**Traitement** :
- Lait hydrolysat protéines (HA)
- Éviction stricte
- Réintroduction progressive après 1 an

### Intolérance Lactose (70% adultes)

**Mécanisme** :
- Déficit enzyme lactase (après 3 ans)
- Lactose non digéré → fermentation

**Symptômes** :
- Ballonnements
- Diarrhée
- Gaz
- Douleurs abdominales

**Diagnostic** :
- Test respiratoire hydrogène
- Test éviction/réintroduction

**Traitement** :
- Éviction lactose
- Ou enzyme lactase (gélules)

## FODMAPS

**Définition** :
- **F**ermentable
- **O**ligo-saccharides
- **D**i-saccharides (lactose)
- **M**ono-saccharides (fructose)
- **A**nd
- **P**olyols (sorbitol, mannitol, xylitol)

**Aliments Riches** :
- Légumes : artichaut, asperge, betterave, oignon, poireau
- Légumineuses : haricots rouges, lentilles, fèves
- Fruits : pomme, poire, pêche, cerise, mangue, melon
- Céréales : blé, orge, seigle
- Lait (lactose)
- Champignons
- Édulcorants : sorbitol, mannitol

**Symptômes** :
- Ballonnements intenses
- Gaz, flatulences
- Diarrhée
- Douleurs abdominales

**Diagnostic** :
- Éviction 4-6 semaines
- Réintroduction progressive (identifier coupables)

**Piège Médicament** :
- **Levothyrox nouvelle formule : mannitol**
- → Troubles digestifs patients
- "Beaucoup de patients se sont plaints depuis le changement de formule"

## SULFITES

**Définition** :
- Conservateurs (E220-E228)
- Antioxydants
- Naturels (raisin) ou ajoutés

**Aliments Riches** :
- **Fruits secs** : abricots, pruneaux (10x plus)
- **Crevettes**
- **Jus citron** (flacons)
- **Vins blancs** (+ rouges, cidre)
- Cornichons, olives
- Moutarde
- Chips
- Jambon

**Symptômes** :
- **Rhinite** (nez coule)
- **Asthme**
- **Céphalées**
- **Flush** (rougeur visage)
- **Urticaire**
- Troubles digestifs

**Syndrome Fernand-Widal** :
- Asthme + polypes nasaux + intolérance sulfites/aspirine

**Diagnostic** :
- Clinique (lien aliments)
- Éviction/réintroduction
